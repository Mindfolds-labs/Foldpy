# FoldPy

FoldPy is a structural visual transformation engine for tensors, geometry, scale, projection and approximate lifting.

## Features

- concentric layers
- border and shell series
- directional generators
- angular perspective matrix
- structural depth hint
- approximate lifting
- RGB <-> LMS
- scale pyramid
- Legendre signatures
- SVG raster bridge
- region graphs
- edge map
- triangulation
- surface mesh hint
- projective score

## Install

```bash
pip install foldpy
